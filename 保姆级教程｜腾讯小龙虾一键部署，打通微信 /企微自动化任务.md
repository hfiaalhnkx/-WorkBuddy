# 保姆级教程｜腾讯小龙虾一键部署，打通微信 / 企微自动化任务.md
> 前言：还在手动写周报、整理网页资料、来回切换软件处理文档？OpenClaw（圈内俗称腾讯小龙虾）是开源AI智能体框架，支持工具调用、任务自动化。借助腾讯云Lighthouse轻量服务器预制镜像，不用折腾Docker、Node环境，一键部署，接入微信/企微后，手机发消息就能远程下达指令，让AI自动完成工作任务。本文全程小白友好，几乎不用敲代码，跟着步骤就能落地。

## 一、部署前准备清单
动手之前，先备好下面几项资源，避免中途卡壳：
1. 腾讯云账号，完成实名认证，用于购买Lighthouse轻量应用服务器；
2. 大模型API密钥：推荐Coding Plan，作为小龙虾的“思考大脑”；
3. 企微账号（个人可直接注册企业，用于搭建企微机器人通道）；
4. 基础网络环境，浏览器可正常访问腾讯云控制台。

> 配置建议：入门选最低配实例，个人日常自动化任务足够；如果要跑大量文档RAG知识库、高频网页抓取，可升级内存。端口放行：需要开放`18789`端口，这是OpenClaw网关通信端口。

## 二、第一步：腾讯云Lighthouse一键部署OpenClaw小龙虾
1. 登录腾讯云控制台，进入【轻量应用服务器】，点击新建实例。
2. **镜像选择「应用模板」**，在应用列表找到`OpenClaw`预制镜像，这是一键部署的核心，已经预装全部运行依赖，不用手动装环境。
3. 选择就近地域，设置服务器登录密码，确认配置下单，等待实例创建，一般3～5分钟。
4. 实例创建完成，进入服务器详情页，切换到【应用管理】标签，就能看到OpenClaw管理面板入口。

> 优势：传统部署要装Git、Node、Docker，拉镜像、处理环境冲突，小白极易报错；预制镜像直接跳过全部环境搭建，开箱即用。

## 三、第二步：配置模型，给小龙虾装上AI大脑
1. 在OpenClaw后台模型（Models）配置页，填入你的模型API Key，选择对应的大模型。
2. 点击**一键添加并应用**，系统自动连通大模型接口，等待页面提示保存成功。
3. 连通测试：在后台简单发送一句消息，验证模型能否正常返回内容。
> 注意：如果提示调用失败，优先检查API Key是否复制完整、接口地址是否正确、模型额度是否充足。

## 四、第三步：通道配置，接入企业微信（稳定推荐）
企微通道稳定性更强，适合长期自动化任务，是大多数人的首选方案。
1. 打开企业微信管理后台 work.weixin.qq.com，登录你的企微账号。
2. 左侧菜单找到【管理工具】→【智能机器人】，选择手动创建机器人，API模式。
3. 随机获取Token、EncodingAESKey，记录Bot ID和Secret，**Secret只展示一次，务必保存**。
4. 回调地址填写：`https://服务器公网IP:18789/wecom-app`
5. 返回OpenClaw后台【通道Channels】，选择企业微信，依次填入Bot ID、Secret，点击添加并应用，网关会自动重启生效。
6. 在企微后台获取机器人二维码，企微扫码添加机器人，即可在企微聊天窗口直接和小龙虾对话。

## 五、第四步：接入个人微信通道（扫码快速绑定）
如果你想用个人微信直接操控小龙虾，可以启用微信插件通道：
1. 在OpenClaw插件市场，安装微信通道插件`@tencent-weixin/openclaw-weixin`。
2. 在通道管理选择微信，启动登录流程，页面生成绑定二维码。
3. 打开微信扫一扫，确认授权绑定，等待通道连接成功。
> 提示：微信通道为插件方案，仅支持私信交互；企微通道支持群聊、消息推送，适合团队自动化场景。

## 六、第五步：安装技能插件，开启自动化任务
打通IM通道后，给小龙虾安装技能，让它从单纯聊天升级成自动化数字员工。进入OpenClaw技能市场，按需安装插件：
- 网页抓取：指令抓取网页内容、摘要资讯；
- RAG文档知识库：上传PDF、Markdown，随时提问文档内容；
- 定时任务：设置周期性任务，自动生成周报、定时信息汇总；
- 文件处理：解析表格、整理笔记，生成文档后直接推送到微信/企微。

**自动化任务实操示例**
直接在企微/微信给小龙虾发指令：
> 每天21点，抓取3篇云计算资讯，整理摘要生成markdown笔记，发送到企微。

小龙虾会自动理解这条定时任务，到点执行，抓取网页、总结内容，完成后主动推送消息。

## 七、测试验证，确认整套链路可用
1. 基础对话测试：发送“你好”，确认小龙虾正常回复；
2. 工具调用测试：下发任务：“帮我搜索一篇Agent文章，提炼3个核心观点”，验证联网+文本总结；
3. 跨设备远程测试：关闭本地电脑，只用手机微信/企微发送指令，验证云端实例持续在线。

## 八、高频踩坑点&解决方案
1. **企微机器人收不到消息**
    检查服务器防火墙，确认18789端口放行；核对回调地址IP、端口，Bot ID和Secret是否复制错误。
2. **模型调用报错，无返回**
    API Key前后空格、额度耗尽、接口地址填写错误，优先核对这三项。
3. **微信通道扫码失败，频繁掉线**
    确认插件版本为最新，服务器网络出口稳定；微信通道稳定性弱于企微，长期任务优先企微方案。
4. **自动化任务不执行**
    检查定时技能插件是否启用，确认网关服务正常运行，查看后台日志排查报错。

## 九、实用落地场景参考
✅ 个人知识库管家：上传读书笔记，手机随时提问文档内容；
✅ 自动化办公助手：定时汇总信息、生成周报，文档处理完成直接推送；
✅ 网页监控：监控目标页面更新，一旦内容变动，微信推送提醒；
✅ 研发辅助：读取技术文档，整理代码注释，提取技术要点。

## 十、重要安全&合规提醒
1. 不要给OpenClaw开放过高服务器权限，避免AI执行高危指令；
2. 定期修改云服务器密码，创建实例快照备份配置；
3. 使用微信、企微通道，遵守腾讯平台规范，严禁用于批量骚扰、违规营销；
4. 自动化任务仅限个人合理使用，禁止滥用爬虫采集。

## 结语
这套方案最大亮点就是**低门槛**，不需要深厚编程功底，依托腾讯云预制镜像一键部署OpenClaw小龙虾。微信/企微作为交互入口，手机随时随地发指令，AI在云端自动完成各类任务。你可以不断新增技能插件，持续拓展小龙虾的自动化能力，打造专属AI数字员工。
